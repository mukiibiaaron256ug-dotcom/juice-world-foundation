SECURE SUPABASE ADMIN VERSION

The Gallery and Partners pages now use Supabase Auth rather than a password embedded in the HTML.

1. In Supabase, open SQL Editor and run SUPABASE-POLICIES.sql once.
2. Your bucket must be named gallery.
3. Your bucket may remain PUBLIC so visitors can view uploaded images. Public buckets do not allow uploads by themselves; the INSERT/UPDATE/DELETE policies restrict those operations to authenticated users.
4. On the website, tap Admin and enter the email/password of the Supabase user you created.
5. Never put a Supabase secret/service_role key in the website.
